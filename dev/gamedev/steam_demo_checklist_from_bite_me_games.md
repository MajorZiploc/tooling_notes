# Steam Demo Checklist

Planning on launching your Steam demo? Here’s everything you should check before you hit that release button. 

<aside>
📺

Accompanying video: https://youtu.be/k9IixsdNP_g

</aside>

## Game

- [ ]  **Demos are not playtests**, the game doesn’t contain any breaking bugs
- [ ]  Demo has a pause menu (pauses the game, access to settings)
- [ ]  Bringing up the Steam overlay (Shift + Tab) pauses the game
- [ ]  Demo shows the core gameplay loop in the first 3 minutes (don’t make the character wander around first)
- [ ]  Demo has a clear ending + CTA
- [ ]  Do not highjack the *Quit* button (don’t open a browser/Steam when the player quits the game)

## Onboarding

- [ ]  Demo starts with a main menu
- [ ]  Demo main menu is animated/dynamic
- [ ]  Demo has links to socials/support from the main menu (e.g. Discord, Steam Discussions)
- [ ]  Demo does not contain opening cutscenes, cinematics or lore dumps
- [ ]  Demo contains some level of tutorial so that the player knows what to do
- [ ]  Controls are explicitly displayed, either through prompts or an input diagram
- [ ]  Demo doesn’t soft-lock non QWERTY players (e.g. AZERTY/QWERTZ)

## Game Feel

- [ ]  SFX on button hover + button click
- [ ]  Scale on button hover & squish on click
- [ ]  Windows are tweened, not instant

## Audio

- [ ]  Demo has music
- [ ]  Demo has an ambient sound layer (wind noise, computer humming, nature,…)
- [ ]  Demo has SFX for all major interactions
- [ ]  SFX are always random pitched
- [ ]  Demo starts with all volume values at 50%

## Settings

- [ ]  Display mode (Windowed, Borderless, Fullscreen)
- [ ]  Vsync toggle
- [ ]  Framerate limiter (dropdown, 30, 60, 120, 165, 240fps + unlimited)
- [ ]  Resolution dropdown
- [ ]  Sound sliders (Main, Music, SFX, Ambient)
- [ ]  Localization (skippable, but strongly suggested)

## Marketing

- [ ]  Uploaded a Demo Release trailer
- [ ]  Demo uploaded to itch.io (assuming <2GB)
- [ ]  Main menu and ending CTA contain wishlists buttons, using UTM links or Steam overlay
- [ ]  Reached out to content creators 1-2 weeks before demo is public for early access (Demo release state override key)
