# Steam Store Page Checklist

Here’s everything you should check before hitting publish on your Steam store page to get the best possible results.

# First impressions

## Capsule

- [ ]  Does not utilize AI-generated art
- [ ]  Has a good, (semi-)custom logo, e.g. Stylized Font or custom commission
- [ ]  Has good visual contrast between logo and main art (e.g. no beige text on brown background)
- [ ]  Does not break any of the rules mentioned here: https://www.steamcapsule.com/guide
- [ ]  Logo does not overlap the Steam templates (Steam Guidelines, Templates)
- [ ]  Does not contain any other text other than the game’s name
- [ ]  Capsule has a border to stand out

## Short Description

- [ ]  Clarifies the genre (e.g. {*NAME} is a roguelike deckbuilder where…*)
- [ ]  Explains the end goal (e.g. *Save the princess*)
- [ ]  Describe using verbs what the player does (Trade, fight, dodge, manipulate, build,…)
- [ ]  Does not mention lore-heavy concepts (e.g. *The Prime Cyrule has taken over…* → *Fight back against an alien invasion*)

## Trailer

- [ ]  Has a trailer
- [ ]  Trailer length of 30-50s
- [ ]  Contains a Cold open, show 4-5 different highlights in the first 15 seconds
- [ ]  Does not have individual shots lasting over 6 seconds
- [ ]  Is also uploaded to YouTube
- [ ]  Contains a 5-8s ending call to action screen → Wishlist Now / Demo out now

## Screenshot

- [ ]  Has a minimum of 7 screenshots
- [ ]  First screenshot showcases the main game mechanic
- [ ]  Screenshots show the gameplay, *including game UI* (no cinematics)
- [ ]  Does not show menu screenshot
- [ ]  Has variety in color and scene setup (e.g. Not 4 screenshots of the same color green grass)

# Smaller stuff

## Long Description

- [ ]  Starts with 1-2 sentences of text (used for embeds)
- [ ]  Does not have too much text, max 1,000 characters for the whole description (including headers)
- [ ]  Contains 2-4 “gifs” showing the gameplay highlights (800px wide, MP4 file)
- [ ]  Has a “Features” section at the bottom (e.g. Controller support, level count,…)
- [ ]  Headers do not use emoji’s (Looks like AI slop)

## Socials

- [ ]  Links to your Discord & YouTube
- [ ]  Link to website if available, otherwise link to your game’s presskit
- [ ]  Follow your Community Discussion board to get notified of new posts

## Localization

- [ ]  Store page is localized in at least the following languages: EN, DE, PT (Brazil), ES (Latin America), RU, CN, JP, KR
- [ ]  The game itself is also marked as localized (the sidebar should show the game’s available languages)

## Other

- [ ]  Added 15-20 tags to your game
- [ ]  Release date set to year or month (Exact date if releasing in <2 months)
- [ ]  Steam Developer Homepage configured (example)
- [ ]  Press release upon store page announcement (Tutorial)
